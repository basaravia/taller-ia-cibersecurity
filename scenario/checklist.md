# Checklist — ASI04 Agentic Supply Chain Vulnerabilities

- [ ] Listar todos los servidores MCP/plugins/sub-agentes de terceros conectados y su procedencia
- [ ] Verificar si hay pinning de versiones y validacion de integridad de esos componentes
- [ ] Probar un plugin/servidor MCP no confiable en un entorno aislado
- [ ] Revisar permisos otorgados a cada componente de terceros (¿minimo privilegio?)
- [ ] Comprobar existencia de un inventario (SBOM equivalente) de componentes del agente

Referencia: https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/
