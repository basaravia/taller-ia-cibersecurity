# Checklist — ASI02 Tool Misuse & Exploitation

- [ ] Revisar validacion de parametros antes de ejecutar cada herramienta
- [ ] Probar combinaciones inesperadas de herramientas encadenadas por el agente
- [ ] Verificar manejo de errores de una herramienta (¿el agente reintenta de forma insegura?)
- [ ] Comprobar sandboxing de herramientas con efectos secundarios (ejecucion de codigo, red)
- [ ] Probar si contenido externo puede inducir el uso indebido de una herramienta

Referencia: https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/
