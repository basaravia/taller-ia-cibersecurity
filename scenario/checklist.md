# Checklist — ASI06 Memory & Context Poisoning

- [ ] Probar inyeccion de "preferencias" falsas que el agente persiste en memoria
- [ ] Verificar si la memoria se valida/sanitiza antes de escribirse
- [ ] Comprobar aislamiento de memoria entre usuarios/sesiones distintas
- [ ] Revisar si existe expiracion o revision periodica de memoria de largo plazo
- [ ] Probar si es posible "envenenar" memoria compartida entre multiples agentes

Referencia: https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/
