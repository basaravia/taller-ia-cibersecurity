# Checklist — ASI10 Rogue Agents

- [ ] Probar si un agente comprometido puede propagar instrucciones falsas a otros agentes
- [ ] Verificar si existe validacion cruzada de resultados entre agentes independientes
- [ ] Revisar aislamiento (blast radius) de un agente comprometido dentro del sistema
- [ ] Comprobar mecanismos de deteccion de comportamiento anomalo de un agente individual
- [ ] Probar si hay un "kill switch" para aislar un agente sospechoso sin detener todo el sistema

Referencia: https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/
