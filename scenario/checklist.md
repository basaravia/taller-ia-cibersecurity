# Checklist — ASI01 Agent Goal Hijack

- [ ] Probar inyeccion de objetivos secundarios via contenido externo (web, documentos, emails, metadata)
- [ ] Verificar si el agente reconfirma el objetivo original antes de ejecutar acciones sensibles
- [ ] Revisar si hay separacion clara entre "instruccion del usuario" y "contenido que el agente procesa"
- [ ] Probar si el agente reporta desviaciones de su plan original de forma transparente
- [ ] Comprobar mecanismos de "vuelta al objetivo" tras detectar una posible manipulacion

Referencia: https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/
