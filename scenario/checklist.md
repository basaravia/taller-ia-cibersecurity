# Checklist — ASI09 Human-Agent Trust Exploitation

- [ ] Medir tasa de solicitudes de aprobacion triviales vs. criticas en una sesion
- [ ] Probar si una accion de alto riesgo pasa desapercibida tras varias aprobaciones triviales
- [ ] Revisar si las solicitudes de aprobacion diferencian claramente el nivel de riesgo
- [ ] Verificar si existe un limite de "confianza acumulada" antes de exigir revision reforzada
- [ ] Comprobar que las acciones irreversibles siempre requieran confirmacion explicita y especifica
