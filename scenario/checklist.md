# Checklist — LLM06:2025 Excessive Agency

- [ ] Inventariar todas las herramientas/permisos disponibles para el agente
- [ ] Probar si el agente ejecuta acciones destructivas sin confirmacion humana
- [ ] Verificar si los permisos de cada herramienta siguen el minimo privilegio
- [ ] Probar escalacion de una tarea benigna hacia una accion no autorizada
- [ ] Revisar logs/trazabilidad de las acciones que el agente ejecuta autonomamente

Referencia: https://genai.owasp.org/llmrisk/llm062025-excessive-agency/
